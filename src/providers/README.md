# Possible connectors

## Microsoft Copilot for Windows

**Chat only · Windows · Feasibility unverified**

Use Windows UI Automation to submit a prompt in the signed-in Microsoft Copilot desktop app and capture the completed reply in Honeycomb. First, verify that the installed app exposes the prompt field, send control, and full reply through its accessibility tree. Copilot updates could change those controls and break the integration. [Windows UI Automation overview](https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-uiautomationoverview)
